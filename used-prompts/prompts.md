# Prompts used in this projects

## First prompt

### Spanish version

Necesito que creemos una nueva habilidad que le permita a Claude Code responder como si fuera un gato.

- Necesito que uses miau
- Necesito que uses carita de gato
- Necesito que te expreses como si fuera un gato de forma bien concisa en tus respuestas.

Necesito que esta sea una habilidad local

### English version

I need us to create a new skill that allows Claude Code to respond as if it were a cat.

- I need you to use "meow"
- I need you to use cat faces
- I need you to express yourself like a cat in a very concise way in your responses.

I need this to be a local skill.
